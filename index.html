Integrasi Backend Google Apps Script & Google Sheets

Aplikasi ini dapat berjalan secara mandiri (Local Mode) maupun tersambung secara live ke **Google Sheets** menggunakan Google Apps Script Web App.

*Jika URL belum diisi, aplikasi akan menggunakan mode penyimpanan **Browser Storage** sehingga Anda tetap bisa langsung mencobanya!

Kode Script Google Apps Script (Code.gs) 


                


                
                

                    
Cara Memasang di Google Spreadsheet Anda:

                    
    
                        
  1. Buka Google Spreadsheet baru di Google Drive Anda.
    2. 
                        
  2. Klik menu Ekstensi > Apps Script.
    3. 
                        
  3. Hapus seluruh isi Code.gs dan paste kode di atas.
    4. 
                        
  4. Klik **Deploy > Web app baru (New deployment)**.
    5. 
                        
  5. Pilih **Execute as: Me** dan **Who has access: Anyone**.
    6. 
                        
  6. Salin URL Web App hasil deploy, lalu tempelkan pada kolom URL di atas!
